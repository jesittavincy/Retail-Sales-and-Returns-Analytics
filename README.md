# Retail Sales and Returns Analytics Dashboard

## Project Overview

This project presents an end-to-end retail analytics solution developed using Microsoft Excel, Power Query, DAX, and Power BI.

The project transforms raw retail transaction data into meaningful business insights by analysing sales performance, returns, products, customers, and countries through interactive Power BI dashboards.

The analysis is based on the **Online Retail II** dataset.

## Problem Statement

Raw retail transaction data may contain duplicates, missing values, cancelled transactions, and other data-quality issues.

This project provides a structured analytical solution to:

- Clean and transform retail transaction data
- Analyse sales performance
- Identify return patterns
- Create business-focused KPIs
- Present insights through interactive dashboards

## Data Preparation

### Excel

- Created a working copy of the raw dataset
- Removed **5,268 duplicate records**
- Identified missing Customer IDs
- Investigated negative quantities and cancelled transactions

### Power Query

- Validated data types
- Created Year and Month fields
- Prepared the transformed data for Power BI analysis

## Dashboard Pages

### 1. Sales Overview

Provides an overview of overall sales performance.

**Key KPIs:**
- Total Sales
- Total Orders
- Total Customers
- Average Order Value

**Visualizations:**
- Monthly Sales Trend
- Top 10 Products
- Country-wise Sales
- Interactive Year, Month, and Country filters

**Purpose:**  
To monitor sales performance and identify top-performing products and markets.

[View Sales Overview Dashboard](./Sales_Overview.png)

### 2. Returns Analysis

Focuses on returned and cancelled transactions and their impact on business performance.

**Key Analysis:**
- Return Rate
- Returned/Cancelled Transactions
- Revenue Impact
- Return Trends
- Top Products and Countries associated with returns

**Purpose:**  
To understand return behaviour and identify areas requiring business attention.

[View Returns Analysis Dashboard](./Return_Analysis.png)

### 3. Executive Insights

Provides a high-level view of business performance for management and decision-making.

**Focus Areas:**
- Revenue Summary
- Top Countries by Revenue
- Top Products by Revenue
- Monthly Revenue Trends
- High-level Performance Indicators

**Purpose:**  
To provide concise business insights and support strategic decision-making.

[View Executive Insights Dashboard](./Executive_Insights.png)
