# Retail Sales and Returns Analytics Dashboard

## Project Overview
This project presents an end-to-end Retail Sales and Returns Analytics Dashboard developed using Excel, Power Query, DAX, and Power BI. The project focuses on cleaning and transforming retail transaction data, creating business metrics, and building interactive dashboards to support business decision-making.

## Tools & Technologies
- Microsoft Excel
- Power Query
- Power BI
- DAX (Data Analysis Expressions)

## Dashboard Pages

### 1. Sales Overview
This dashboard provides an overview of business performance using completed sales transactions.
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Top 10 Products by Sales
- Sales by Country
- Monthly Sales Trend

### 2. Returns Analysis
This dashboard focuses on analysing returned and cancelled transactions.
- Return Rate
- Revenue Impact
- Return Trends
- Product Return Analysis

### 3. Executive Insights
This dashboard provides high-level business insights for decision-making.
- Revenue Summary
- Top Countries by Revenue
- Top Products by Revenue
- Monthly Revenue Trend
